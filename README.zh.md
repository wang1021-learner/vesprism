# Vesprism

这是根目录 [`README.md`](README.md) 的中文页。GitHub 仓库首页默认显示 `README.md`。

**Vesprism** 是 AI 原生桌面开发工作台：侧栏可切 **编码**（改仓库）和 **工作台**（流程画布 / Agent 编制）。引擎是官方 Grok Build 运行时，桌面壳在 `crates/vesprism-desktop`。

```sh
cd crates/vesprism-desktop
npm install
npm run desktop
```

本仓 fork 自 [xai-org/grok-build](https://github.com/xai-org/grok-build)。官方终端版 `grok` 的安装说明看上游，不要用本仓当 CLI 安装页。

现码手册：[`docs/Vesprism-全功能与实现手册.md`](docs/Vesprism-全功能与实现手册.md)。
