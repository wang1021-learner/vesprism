# 功能修改说明：侧栏体验 & 流式输出

> 模块：`jike-grok-desktop`（AIAcong Grok Desktop）  
> 日期：2026-07-24（与当前代码同步）  
> 类型：体验优化（无后端协议变更）

---

## 一、侧栏会话列表滚动条

### 问题

侧栏历史会话列表滚动条与主对话区观感不一致；曾尝试「强制短滑块」，不符合「按内容比例显示」的预期。

### 最终行为

| 项 | 说明 |
|----|------|
| 滑块高度 | **浏览器原生按比例计算**：`可视高度 / 内容总高度` |
| 样式 | 细条（约 4px）、圆角、浅灰；透明轨道 |
| 自定义滚动条 | **已移除**（不再限高、不再自绘滑块） |

### 涉及文件

- `src/App.css`：`.sidebar-recent-list` 使用原生 `::-webkit-scrollbar` 样式  
- `src/components/Sidebar/index.tsx`：列表容器 `overflow-y: auto`  

### 使用说明

- 会话少、几乎一屏装下 → 滑块偏长（正常）  
- 会话多、可滚内容长 → 滑块变短（正常）

## 二、侧栏工作空间收纳与图标

### 问题

1. 工作空间折叠用 `max-height: 2000px` / `grid 0fr` 等方案时：可能裁切、留白、动画不跟手  
2. 折叠后子列表仍挂在 DOM 上，空间多时偏重  
3. 工作区标题 `sticky` 导致滚动时顶部卡住残影  
4. 文件夹图标亮蓝、开合只靠旋转，观感差  

### 最终行为

| 项 | 说明 |
|----|------|
| 折叠策略 | **展开挂载、收起卸载**（`CollapsibleWorkspaceBody`：`if (!open) return null`） |
| 高度动画 | **不做**（避免 WebView 留白 / 裁切 / 定时器竞态） |
| 默认展开 | 当前工作空间展开，其余折叠；激活会话所在空间自动展开 |
| 工作区标题 | **不 sticky**，随列表一起滚走 |
| 文件夹图标 | 展开 / 折叠 **两套 SVG path**；中性灰色，无亮蓝 |

### 方案取舍（结论）

| 方案 | 结果 |
|------|------|
| `max-height: 2000px` | 否：有上限裁切 / 空驶 |
| `grid 0fr ↔ 1fr` | 否：WebView 中高度常收不掉，留下透明空白 |
| `scrollHeight` + JS 动画再卸载 | 否：能修空白，但实现复杂、有连点等边角 |
| **`open ? children : null`** | **采用**：不留白、不裁切、DOM 轻、无竞态 |

侧栏折叠是离散开/关，立即挂载/卸载即可；高度动画非必要。

### 实现要点

```tsx
// Sidebar/index.tsx
function CollapsibleWorkspaceBody({ open, children }) {
  if (!open) return null
  return <div className="sidebar-workspace-body">{children}</div>
}
```

- `FolderIcon open={...}`：打开 / 合上文件夹 path 切换  
- 颜色：折叠浅灰、展开略深、当前工作区略加重、hover 近黑  
- 布局：侧栏 / 主区悬浮白卡片（圆角、浅灰底），与整体 UI 一致  

### 涉及文件

- `src/components/Sidebar/index.tsx`：`CollapsibleWorkspaceBody`、`FolderIcon`、工作空间折叠状态  
- `src/App.css`：文件夹图标色、工作区标题（无 sticky）、侧栏卡片样式

## 三、思考 / 回答流式输出抖动与卡顿

### 问题

1. **思考推演**（`agent_thought_chunk`）输出时界面上下抖动  
2. **AI 回答**（`agent_text_chunk`）流式不够丝滑  
3. 历史会话向上滚动后，被固定时长定时器强行拉回底部  
4. 根因归纳：  
   - 每个 chunk 直接 `setState`，重绘过密  
   - 滚动使用 `smooth` 或 `scrollTop` + `scrollIntoView` 双重滚动  
   - 滚动在绘制**之后**执行 →「先长高再跳」  
   - 回答侧每帧全量 Markdown + 语法高亮，开销大  
   - 旧版 `setTimeout` 锁底窗口（约 1.5～2.5s）误伤阅读历史  

### 最终行为

| 能力 | 修改前 | 修改后 |
|------|--------|--------|
| 流式文本更新 | 每个 chunk 整段进 React | **打字机缓释**：chunk 入队，按帧吐字；积压多时提速 |
| 贴底滚动时机 | `useEffect` + 多段 `setTimeout` | **`useLayoutEffect` + `ResizeObserver`**，无固定锁底窗 |
| 滚动方式 | smooth / 双重滚动 | **仅 `scrollTop` instant 贴底** |
| 用户上滑阅读 | 定时器到期后可能被拽回 | **`userInteractedUp` + 滚轮立刻切断** |
| 回答 Markdown | 流式时也做语法高亮 | **生成中关闭高亮，结束后再开** |
| 历史消息重渲 | 末条更新可能牵连整表 | **`memo` 历史气泡不重渲** |
| 切会话 / 新建 | 打字机 rAF 可能残留 | **`discardTypewriter` 丢弃队列** |

### 功能细节

#### 1. 流式打字机缓释（`App.tsx`）

```text
后端 chunk ──► pendingText 队列 ──► stepTypewriter（rAF）──► setMessages 追加一小段
                      │
         turn_ended / 工具卡片 / 角色切换 ──► flushTypewriterNow（整段冲刷）
         切会话 / 新建 / 发送前 ──► discardTypewriter（丢弃，不写入）
```

规则：

- 同角色流式 `append`：文本进入 `typewriterRef.pendingText`  
- 每帧吐字量（按码点，避免 emoji 截断）：  
  - 积压 `>40`：约 `ceil(len/3)`  
  - `>15`：3；`>6`：2；否则 1  
- 角色切换、工具调用、`turn_ended`、错误： **`flushTypewriterNow` 立刻冲刷**，避免丢字  
- 新建会话 / 选历史 / 删除当前会话 / 发送新消息前：**`discardTypewriter`**，避免旧 rAF 灌进新会话  
- 取消生成：先 `flushTypewriterNow`，尽量保住已缓冲文字  

**flush 追加判定**：以消息列表**末条**的 `role` 是否与缓冲角色相同为准（不依赖 `streamingRole` 是否仍为该角色），避免工具卡片前先清 `streamingRole` 导致误拆新气泡。

#### 2. 消息列表贴底（`MessageList.tsx`）

| 机制 | 作用 |
|------|------|
| `useLayoutEffect` | `messages` 变且未上滑 → 绘制前 `scrollTop = scrollHeight` |
| `ResizeObserver` | 监听 `.messages-container` 高度（高亮/代码块撑开）→ 未上滑则贴底 |
| `onWheel`（`deltaY < 0`） | 向上滚轮**立刻** `userInteractedUp = true`，切断贴底 |
| `onScroll` | `gap < 30` 恢复贴底；`gap > 100` 暂停贴底 |
| 切会话 / 加载完成 | 重置 `userInteractedUp`，贴底一次 |
| `hasMessages` 依赖 | 空列表→首条消息时正确挂上 ResizeObserver |

已移除：固定毫秒强制贴底窗口、多段 `setTimeout` 补滚、`scrollIntoView` 双重滚动。

**新增 props**

| prop | 含义 |
|------|------|
| `streaming` | `status === 'generating'`；仅**最后一条**消息生效 |

#### 3. 流式 Markdown 减负（`AssistantMarkdown.tsx` / `MessageItem.tsx`）

- 仅最后一条且 `streaming=true` 时关闭 `rehype-highlight`  
- `remark-gfm` 仍开启  
- 生成结束后再做一次代码高亮  

#### 4. 布局隔离（`App.css`）

- `.message-row { contain: layout style; }`  
- 减轻单条消息增高时对兄弟节点的布局连带  

### 涉及文件

| 文件 | 改动要点 |
|------|----------|
| `src/App.tsx` | 打字机、`flush` / `discard`、工具卡片先 flush；切会话丢弃队列 |
| `src/components/Chat/MessageList.tsx` | ResizeObserver + 手势贴底；`hasMessages` |
| `src/components/Chat/MessageItem.tsx` | `memo` + `streaming` 透传 |
| `src/components/Chat/AssistantMarkdown.tsx` | 流式跳过语法高亮 |
| `src/App.css` | 侧栏滚动条；消息行 `contain`；侧栏卡片与文件夹样式 |
| `src/components/Sidebar/index.tsx` | 工作空间挂载/卸载折叠；文件夹图标 |

### 未改动的部分

- 后端 IPC 事件类型与字段不变  
- 思考气泡结构（💭 思考推演 + `<pre>`）不变  
- 助手 GFM 能力不变，仅流式阶段暂不高亮

## 四、已修漏洞与仍存在边界

### 已在代码中修复

| 问题 | 处理 |
|------|------|
| 工具调用时思考拆成两条气泡 | flush 看末条 role；先 flush 再清 `streamingRole` |
| 切会话后旧字灌进新会话 | `discardTypewriter()` |
| emoji 被截断 | `takeCodePoints` 按码点截取 |
| 空会话首条消息 ResizeObserver 未挂 | 依赖 `hasMessages` |
| 思考流式滚动抖动 | instant 贴底 + 打字机减频 |
| 历史上滑被 timer 拽回 | 改为 `userInteractedUp` + ResizeObserver |
| 工作区折叠留白 / 裁切 | 改为挂载/卸载，无高度动画 |
| 工作区 sticky 顶栏残影 | 去掉 sticky，标题随列表滚 |
| 文件夹亮蓝难看 | 中性灰 + 开合两套 path |

### 仍存在的边界（可接受）

| 点 | 说明 |
|----|------|
| 打字机每帧仍 `setState` | 长文仍有一定更新频率；观感优先于极致性能 |
| `turn_ended` 整段 flush | 队列剩余字可能一次性补上 |
| `streaming` 绑 `status==='generating'` | status 先 idle、队列未空时可能提前开高亮 |
| 触控板 / 拖条上滑 | 主要靠 `gap>100`，比滚轮切断略慢半拍 |
| `gap` 30～100 死区 | 有意防抖 |
| Markdown 全量 re-parse | 流式每帧仍整文解析；已用关 highlight + memo 缓解 |
| 工作区折叠无高度动画 | 有意取舍，换零边角问题 |

## 五、验收建议

1. **侧栏滚动条**  
   - 会话少 / 多时滑块比例正常，可拖可滚  

2. **工作空间收纳**  
   - 折叠后标题下紧接下一项，**无空白**  
   - 折叠后该空间会话不在 DOM 中（展开才出现）  
   - 列表滚动时工作区名称一起滚走，顶部无残影  
   - 文件夹开合图标可辨、颜色中性  

3. **思考 / 回答流式**  
   - 无明显上下抖；结束后代码高亮正常  
   - 上滑阅读不被拽回；回到底部后继续跟随  

4. **边界**  
   - 思考 → 工具 → 回答：文字不丢、不拆重复 thought  
   - 生成中切会话 / 新建：旧缓冲不进入新会话  
   - `turn_ended` / 取消：缓冲按策略落盘（取消前 flush）  
   - 含 emoji 的流式文本完整

## 六、变更关系简图

```text
【侧栏】
会话列表 ──► 原生比例滚动条
工作空间 ──► FolderIcon（开/合 path，中性灰）
         ──► CollapsibleWorkspaceBody：open ? 挂载 : null
         ──► 标题不 sticky，随列表滚动

【对话流式】
后端 chunk
    │
    ▼
typewriter 队列（pendingText）
    ├─ rAF stepTypewriter ──► 每帧少量码点 ──► setMessages
    ├─ flushTypewriterNow  ──► 整段并入末条（同 role）
    └─ discardTypewriter   ──► 切会话 / 新建 / 发送前丢弃
    │
    ▼
MessageList
    ├── useLayoutEffect：!userInteractedUp → scrollTop 贴底
    ├── ResizeObserver：容器变高 → 贴底
    ├── onWheel 上滚 → 立刻停贴底
    └── onScroll：gap<30 恢复 / gap>100 暂停
            │
            ├── MessageItem（memo，仅末条 streaming）
            │     ├── thought：pre
            │     └── assistant：流式无 highlight / 结束后有 highlight
            └── 历史消息 memo 跳过重渲
```
