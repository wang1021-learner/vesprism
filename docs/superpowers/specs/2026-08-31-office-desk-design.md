# 办公桌（Cowork 式）设计 · 2026-08-31

第四套产品，和编码分开。第一期是 **demo**：材料夹 → 计划 → 可交文件。不接引擎，不操作电脑。

## 学 Claude Cowork 的什么

学交互，不学配色（Claude 暖橙；我们用 Vesprism 冷纸墨）。

| Cowork | 我们 |
|--------|------|
| 交代任务，不是闲聊 | 起手卡 + 输入框，产出是文件 |
| 先问范围/格式，再出计划 | demo 用预置四步；正式版再接提问 |
| 左任务 / 中对话+计划 / 右进度与产物 | 侧栏任务，主区计划，右栏材料/预览 |
| 文件夹当工作区 | 演示夹「本周材料」，不是 Git 仓库 |
| 预览它写出的文件 | 右栏预览；正式版走官方 docx/pptx 技能 |
| Ask / 自动 权限 | 沿用现有审批条；demo 不调工具 |
| 内置浏览器、抢键鼠、云端、手机 Dispatch | 第一期不做 |

## 不做什么

- 不塞进编码。顶栏独立「办公」。
- 不另写 Agent 循环。正式版会话仍走 `xai-grok-shell`。
- 不做飞书/钉钉主路径。
- 不做虚拟桌面。

## Demo 范围（已落地）

- 产品 id `office`，面板 `office-desk`，不 startSession（避免抢编码 cwd）。
- 空态不是封面：问候 + 输入框内嵌目录/权限/格式/附件 + 场景胶囊 + 三条示例任务。
- 侧栏：新任务、技能、专家、知识库、定时、连接器、历史（演示列表）。
- 干活右侧固定三块：计划、正在调用、产物。电脑操作胶囊会提示未接管。
- 主区用画布灰、输入用白、胶囊带浅色，避免整页死白。

## 正式版（demo 之后）

1. 授权本机材料夹，cwd 锁在该夹（类似写完的 `writing/`）。
2. 发布时 Rust 编译流程；办公起草走官方技能 / 已发布 sidecar，不从前端送脚本。
3. 产物落到材料夹，导出真 Office 文件。
4. 权限：写文件走现有审批；电脑操作保持默认关。
