# 官方代码合并与二次开发工作流

> 更新日期：2026-08-05  
> 适用：`grok-build` monorepo 内桌面端（`vesprism-desktop` / `grok-session`）相对上游官方 `xai-grok-*` 的合并与改功能节奏。

---

## 1. 目标

| 目标 | 说明 |
|------|------|
| **拉官方** | 同步 monorepo 上游能力（引擎、工具、ACP 扩展） |
| **保留双方** | 官方修复/新功能 + 桌面二次开发（UI、隔离目录、Tab、问卷…）都不丢 |
| **改功能前先看官方** | 新需求先查官方是否已有实现，避免重复造轮子 |

---

## 2. 仓库边界

| 路径 | 归属 | 合并策略 |
|------|------|----------|
| `crates/codegen/xai-grok-*`、`crates/common/*` 等官方 crate | **上游优先** | 合并时以官方 diff 为主；本地改动尽量少、可回放 |
| `crates/grok-session` | **桌面胶水层** | 允许扩展事件/oneshot；合并后需回归 ACP 客户端 |
| `crates/vesprism-desktop` | **二次开发主战场** | 几乎全部桌面 UI；合并官方时冲突面小 |
| `docs/桌面端-*.md` | 桌面产品文档 | 合并后对照源码更新清单 |

原则（见 `docs/官方代码修改原则.md` 若存在）：

1. **能不改官方就不改官方** —— 优先在 `grok-session` / 桌面端适配。  
2. **必须改官方时**：改动面最小、带测试、合并说明写清。  
3. **功能前检索**：工具名 / ACP method / pager 视图是否已有。

---

## 3. 推荐流程（拉官方 → 合并 → 做功能）

```
① 同步上游
   git fetch origin   # 或上游 remote
   # 记录当前桌面分支 tip

② 合并 / rebase
   优先 merge，便于保留双方历史
   冲突：官方 crate 偏官方；vesprism-desktop 偏本地

③ 编译与冒烟
   cargo check -p grok-session -p vesprism-desktop
   cd crates/vesprism-desktop && node scripts/verify.mjs
   手动：冷启动 / 发消息 / 权限 / 多 Tab

④ 对照官方「有没有现成能力」
   工具：crates/codegen/xai-grok-tools
   ACP 扩展：xai-grok-shell / xai-grok-pager（ext_method 名）
   桌面只做：事件映射 + UI

⑤ 再改功能 / 写 UI
   优先走官方事件与 command，不重写引擎

⑥ 更新文档
   docs/桌面端-现状架构与功能文档.md §0.1 改动清单 + §6 矩阵
```

### 3.1 合并前检查清单

- [ ] 当前桌面未提交改动已 stash 或 commit  
- [ ] 记下 `SOURCE_REV` / 上游版本  
- [ ] 合并后 `cargo check` 关键关键 crate  
- [ ] 桌面 `tsc` / `verify.mjs`  
- [ ] 关键功能回归：权限、问卷、子 Agent、多 Tab  

### 3.2 「官方有没有实现」怎么查

| 想做的能力 | 先看 |
|------------|------|
| 工具是否存在 | `xai-grok-tools` 注册表 / `versions.rs` |
| 是否有 ACP 反向请求 | pager `ext_method` 路由、shell leader |
| 是否有通知 | `x.ai/session_notification` SessionUpdate 变体 |
| 桌面是否已接 | `grok-session` SessionEvent、`FrontendEvent`、bridge command |

**示例：**

| 需求 | 官方已有 | 桌面该做 |
|------|----------|----------|
| 多 Agent | `spawn_subagent` + Subagent* 通知 + cancel/get | 条 / 新标签 / 取消 UI |
| 问用户 | `ask_user_question` + `x.ai/ask_user_question` | 问卷 UI + 工具卡 |
| 会话撤销 | `x.ai/rewind/*` | **仍缺** Rewind UI |
| Workflow 图 | workflow 工具 | **仍缺** 可视化 |

## 4. 冲突处理口诀

| 冲突位置 | 倾向 |
|----------|------|
| 官方工具实现 / agent prompt | 官方 |
| `grok-session` 事件枚举 | 两边都留：官方新事件 + 桌面 oneshot |
| `vesprism-desktop` | 本地 |
| `Cargo.lock` | 以编译通过为准重新生成 |
