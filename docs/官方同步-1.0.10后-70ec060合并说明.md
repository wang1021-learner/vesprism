## 2. 官方这批改了什么

摘自 sync 提交说明。changelog 仍停在 1.0.10，下列是 1.0.10 **之后**合进 monorepo 的内容。

### 引擎 / 可被桌面直接吃到的

| 官方改动 | 桌面要不要动手 |
|----------|----------------|
| Hooks：`UserPromptSubmit` 可拦截发送；被拦的 prompt 不进 chat-state | **直接受益**。桌面 `session/prompt` 走同一条 ACP；仓库 Hooks 打开时生效 |
| 子 agent 首轮 `prompt_admitted` 竞态：未 ack 就完成不再卡死 | **直接受益** |
| `send_subagent_message` 工具：父会话给仍在跑的子 agent 发跟进消息 | **可复用、桌面未接 UI**。模型可自己调工具；侧栏子 Tab 不必另写通道 |
| Auto 模式把 `mkdir` / `touch` 当安全创建自动放行 | **直接受益**（仅信任模式） |
| 子进程网络限制改走 `restrict_child_network` | **直接受益**（Linux 沙箱） |
| 工作流写盘后 smoke-check 作者脚本 | **直接受益**。画布发布的 Rhai 被模型改文件时会校验 |
| 鉴权决策收成 `AuthBackend` trait | 胶水无破坏；登录仍走桌面 `account.rs` |
| Headless 会话默认 always-allow | **不影响 Vesprism**。桌面用 `spawn_agent_local`，不是 `run_headless` |

### 几乎纯 TUI / CLI / 仪表盘，桌面不必抄

Kitty overlay、Warp 跳帧、paste 末尾换行不自动发送、dashboard 工作区、span profiler、websocket 0.28、TUI 模型 slug 改 grok-4.6、voice Linux 回退、installer Bearer 修复。

### 结构拆分

- `crates/codegen/xai-grok-home` → `crates/codegen/xai-dirs`
- 新 workspace 成员：`xai-grok-dashboard-store`（TUI dashboard 本地库，桌面不用）
- `xai-tool-protocol` 继续扩 bot_relay 契约（桌面暂不用）

## 4. 能不能复用（结论）

**能，多数不用改桌面就会变好。** 本 merge 范围内不写新 UI。

优先记下、以后再接：

1. **子 agent 跟进消息**：引擎已有 `send_subagent_message`；桌面子 Tab 输入框目前仍是普通 `session/prompt`，不必平行再造一条 IPC。
2. **Hooks 拦发送**：设置里已有 Hooks 信任；可在审批条附近补一句「UserPromptSubmit 拦下的消息不会发出」。
3. 不必做：dashboard-store、bot_relay、TUI overlay、headless always-allow。

**不要**为跟进消息再写一套子会话广播。工具已经在 `xai-grok-tools` 里。
