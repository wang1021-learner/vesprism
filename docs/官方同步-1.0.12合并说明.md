## 2. 官方这批改了什么

摘自 sync 提交说明与 `CHANGELOG.md` 1.0.11 / 1.0.12。上一轮 70ec060e 已吃掉部分 1.0.11 引擎项（mkdir/touch 自动放行、`send_subagent_message` 等），下面只记对本 merge 仍新的内容。

### 引擎 / 可被桌面直接吃到的

| 官方改动 | 桌面要不要动手 |
|----------|----------------|
| SessionStart Hook 落盘进沙箱 config 导致逃逸 | **直接受益**（安全） |
| 采样瞬时失败自动重试，不再整轮杀掉 | **直接受益** |
| Length 截断时仍执行已完成的工具调用 | **直接受益** |
| 压缩失败露出真实错误，截断走 typed error | **直接受益**；桌面 error banner 会收到更具体文案 |
| PreToolUse 解析 `additionalContext`、可 defer；Hook 可向用户提问 | **直接受益**。审批条已接 `x.ai/security_findings`；Hook ask 走官方问卷通路 |
| 调度器保留完整 UUID、完成的循环任务会停 | **直接受益**。桌面 `/loop` 面板 |
| MCP 启动不再 batch cap；OAuth 离开 session spawn 路径 | **直接受益**。多 MCP 冷启动更快 |
| 断开连接不再让子 agent 空等 2s | **直接受益** |
| Windows 单一 home resolver（`xai-dirs`） | 桌面仍强制 `GROK_HOME=~/.vesprism`；引擎内部路径更稳 |
| 图宽高钳到 2000px | **直接受益** |
| 父会话 Queue delivery base | **直接受益**。桌面排队已接 `x.ai/queue/*` |
| `xai-message-delivery-core` | 协议层；桌面暂不用 |

### 几乎纯 TUI / CLI，桌面不必抄

gboom 拆成独立 crate、pager input/search 挪到 `xai-grok-pager-render`、安装包压缩、TUI 死代码清理、Playground bin 从 pager `Cargo.toml` 删掉。

## 4. 能不能复用（结论）

**能，多数不用改桌面就会变好。** 本 merge 范围内不写新 UI。

优先记下、以后再接：

1. **Hook ask / PreToolUse additionalContext**：引擎已向用户提问；确认桌面问卷/审批条能画出来。  
2. **压缩 / 截断 typed error**：看桌面 error banner 文案是否够人话。  
3. 不必做：gboom、pager-render 搬家、bot_relay 扩契约、TUI playground bin。

**不要**为消息投递再写一套通道。官方 `xai-message-delivery-core` 和 Queue delivery 已经在引擎里。
