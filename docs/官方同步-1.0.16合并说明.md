## 2. 官方这批改了什么

摘自 `CHANGELOG.md` 1.0.13 / 1.0.14 / 1.0.15 / 1.0.16。引擎侧多数桌面不用改就会变好。

### 直接受益（引擎已吃，桌面无额外 IPC）

| 官方改动 | 桌面要不要动手 |
|----------|----------------|
| 采样瞬时失败自动重试 | **直接受益** |
| Length 截断仍执行已完成工具调用；截断后自动续写 | **直接受益** |
| 压缩失败露出真实错误 | **直接受益**；error banner 文案更具体 |
| 过期 token 不再丢长会话 | **直接受益** |
| 子 agent 刚 spawn 立刻发消息不再失败；spawn 等待更久 | **直接受益** |
| 子 agent / 任务输出等待默认 1 小时 | **直接受益**（`get_command_or_subagent_output`） |
| 循环任务完成会停；调度器 UUID | **直接受益**。桌面 `/loop` |
| MCP 启动不再 batch cap；OAuth 离开 session spawn | **直接受益** |
| 会话启动预热模型连接；MCP 后台初始化 | **直接受益** |
| 符号链接逃逸 deny；`GROK_CHANNEL` RCE 修 | **直接受益**（安全） |
| PostToolUse 可向模型反馈 | **直接受益** |
| 失败的 task/todo 工具卡不再消失 | **直接受益** |
| MCP 2026-07-28 elicitation 多轮 | **直接受益**。桌面已有 `x.ai/mcp/elicit` UI |
| 父会话 Queue / interject 给子 agent 续指令（Steer） | **直接受益**。桌面排队/插话已接；**不要**发明 `x.ai/subagent/steer` |

### 本轮桌面胶水已接

| 官方改动 | 桌面接法 |
|----------|----------|
| `session/set_config_option` + `configOptions` | `grok-session` 发 `ConfigOptions`；`set_model` 先走 config option，失败再 `set_model_with_label` |
| 企业 `requirements.toml` 钉死模型列表 | 前端 `filterModelsByPolicy`，Composer / App / CanvasComposer 共用 |
| 模型可按 reasoning-effort 声明不同 id | Composer 优先用官方 `reasoning_effort` 选项值（可能是 model id） |
| 绑定期 MCP servers（`session/new.mcp_servers`） | `start_spawned_with_mcp`；`begin_fresh_session` 把组装单 MCP 带上 |
| `RetryState::Retrying.error_type` | 传到前端 toast（鉴权 / 上下文过长 / 限流） |
| Hook ask 标题带 ` — ` | `permissionLead` 原样展示官方 title |
| 托管 MCP / 插件 / 商店策略 | MCP 行读 `policyDenied` / `disabledReason`，开关锁死；插件 `mcpStatus=blocked` → 已拦截；商店源 error 含 `strictKnownMarketplaces` 禁止安装 |

### 几乎纯 TUI / CLI，桌面不必抄

gboom、pager 滚动/输入、Windows CLI 压缩包、`/copy` `/export` 提示、extensions modal spinner、TUI playground。

## 4. 能不能复用（结论）

**能。** 引擎修复桌面直接吃；本轮桌面只补胶水，不平行实现 agent。

已接：configOptions、effort 分 model id、企业模型钉死、绑定期 MCP、retry `error_type`、Hook ask 标题、MCP/商店策略 verdict。

**不要**为 Steer 再写一套 ACP。父会话 `queue` / `interject` / `send_subagent_message` 已经够。

不必做：gboom、pager 搬家、bot_relay 扩契约、TUI playground。
