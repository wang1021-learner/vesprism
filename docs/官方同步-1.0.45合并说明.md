## 2. 官方这批改了什么

摘自 `crates/codegen/xai-grok-shell/CHANGELOG.md` 1.0.25 … 1.0.45。引擎侧多数桌面不用改就会变好。TUI chrome 不抄。

### Breaking / 行为变化（桌面要盯）

| 官方改动 | 桌面影响 |
|----------|----------|
| **1.0.25** 实时用户消息回显改为 opt-in，用来消掉 ACP 客户端双份 prompt | **要回归**。`grok-session` 的 `ClientCapabilities` 仍只有 `terminal(true)`，没有打开 live echo。桌面自己画用户消息，预期是不双份；确认消息也不丢 |
| **1.0.25** 后台任务列表改为可恢复的 durable snapshot | **要回归**后台任务条。1.0.24 已接 BackgroundTasks，形状变了之后看重连 / 冷启动是否还在 |
| **1.0.44** 同文件的并行编辑改为串行，无关工具仍并发 | **直接受益**；看多工具改同一文件时卡片顺序 |
| **1.0.44** 模型可广告多个上下文窗口；`/model` 与 `/context-window` 先选窗口 | **风险**：桌面没有上下文窗口选择 UI。切模型走官方默认（列表第一项）。不要假设窗口和 1.0.24 一样 |
| **1.0.19 遗留** folder trust 闸项目 instructions / skills | **仍要回归**。项目技能变少时先查信任，不要当成技能丢了 |
| **MemoryFiles** 通知多了 `enabled` / `disabled_reason` / `capture_enabled` / `dream_enabled` | 桌面匹配用 `{ files, .. }`，面板仍只认文件列表。`enabled` 默认 true |

### 直接受益（引擎已吃，桌面无额外 IPC）

| 官方改动 | 桌面要不要动手 |
|----------|----------------|
| 子 agent 可省略 type（默认 general-purpose）；可继承父模型；自定义 agent 能被 `spawn_subagent` 选中 | **直接受益** |
| 插话打断子 agent 的长时间等待 | **直接受益** |
| MCP 结构化 JSON 结果；token 文件每次请求重读；2026-07-28 服务器能连上 | **直接受益**（桌面已有 elicit UI） |
| `/rewind` 在旧压缩检查点被扫掉后仍可用基线检查点 | **直接受益**（桌面 Rewind UI 仍缺） |
| Workflow pause / stop 控制源 | **直接受益**；1.0.24 已放行 `workflowGate` |
| 成功的 hook 不再刷状态 | **直接受益** |
| Memory v2 从 init 失败里恢复 | **直接受益** |
| Windows：ARM64 首次 TLS 崩溃、Client-ProjFS 未启用时的启动崩溃、`grok clone` 的 gitconfig 反斜杠 | **CLI / 引擎受益**；桌面进程不走 `grok clone` |
| 后台 shell 以实时任务行流出 | **引擎受益**；桌面任务条要看快照是否接得住 |

### 机会（未接，可选）

| 官方改动 | 桌面可做可不做 |
|----------|----------------|
| `/context-window` 与切模型时的窗口选择 | 设置或模型菜单里加一档；现在用官方默认 |
| MemoryFiles 的开关与禁用原因 | 记忆面板可后补 |
| MCP 结构化 JSON | 工具卡可后补展示 |
| 模型 notice banner | TUI 提示条，桌面不必抄 |

### 几乎纯 TUI / CLI，桌面不必抄

Dashboard、pager、主题、`/usage` footer、vim 键、欢迎屏、minimal 模式、Seatbelt（仅 macOS）、`grok worktree create`、WinGet 更新文案。

## 3. 冲突 / 适配怎么解

口诀：官方 crate 用上游正文，再把桌面语义嵌回去。能在 `grok-session` / 桌面修的，不改官方。

| 文件 | 倾向 | 处理 |
|------|------|------|
| `Cargo.toml` | 本地 | 保留 `grok-session` / `grok-gui-poc` / `vesprism-desktop/src-tauri`，exclude 旧 `jike-grok-desktop` |
| `Cargo.lock` | 以编译为准 | 合并提交跟官方（`find-msvc-tools` **0.1.13**，无 Tauri）。工作区回灌桌面 crate，并 `cargo update -p find-msvc-tools --precise 0.1.12`。0.1.13 让 `cc` 1.2.48 在 Windows 上把 `FILE_ATTRIBUTE_TEMPORARY` 当成 `i32`，`custom_flags` 要 `u32` |
| `SOURCE_REV` | 官方 | `559751fd…` |
| `SessionModelSwitch` | 上游形状 + 一字段 | 增加 `extra_human_rules`。`SetSessionModel { switch, responds_to }` 用官方形状。skip 重写提示时，模型没变且没有 label / persona 才跳过 |
| `agent.rs` | 两边都留 | `set_system_prompt_label` 与官方 `set_rendered_prompt` 都保留。relabel 走后者 |
| flow 挂载 | 本地语义 | `resolved_mounted_flows` 写在真正的 `SessionHandle` 上；返回值用官方 `SessionInitResult`。sampler 仍 `inject_mounted_flow_tools`。子 agent 同时保留 `inherited_flows` 与 `memory_config` |
| `tool_calls` | 本地语义 | 保留 `parallel_gate_exclusive`（Execute 独占）和 flow 局部变量。span 助手已迁到官方 telemetry，不把旧副本捡回来 |
| bash grant | 本地语义 | `mod canonicalize` 仍在。`matched_command_grant` 两边都 OR `words_covered_by_grants`。禁止把裸 `bash` / `sh` 存成 always-allow 的逻辑在已自动合并的 `grants/bash_grants.rs` |
| 安全预检 | 本地语义 | 权限请求前 `prompter.set_security_findings`，meta 键 `x.ai/security_findings` |
| `policy.rs` | 最小公开 | `InlineShellScript` 与 `shell_dash_c_script` 从 `pub(crate)` 改为 `pub`，workspace 的 canonicalize 继续用官方分类器 |
| 测试字面量 | 跟上新字段 | `SessionModelSwitch` 补 `extra_human_rules: None`。recap 测试保留本地的 per-turn override 用例 |
| `grep` 再导出 | 两边 | 官方 card 再导出 + 本地 `GrokIntegerSchema` 再导出 |
| `grok-session` | 桌面胶水 | `spawn_agent_local` 第 8 参：任务内的 `Rc<RefCell<Option<Rc<MvpAgent>>>>` keepalive。`MemoryFiles` 用 `{ files, .. }` |
| 桌面模型目录 | 桌面胶水 | `XAI_API_BASE_URL_DEFAULT` 已私有。改用 `EndpointsConfig::default().xai_api_base_url`（仍认 `GROK_XAI_API_BASE_URL`） |

残留冲突标记：源码侧未见。`xai-grok-markdown` bench 里的 `=========` 是数据，不是冲突。

`spawn.rs` 与 recap 测试在 Windows 上曾整文件写成 CRLF。`core.autocrlf=true`，入库 diff 与 `--ignore-cr-at-eol` 行数一致，不是整文件换行。

## 4. 能不能复用（结论）

**能。** 子 agent、MCP、workflow、rewind、Windows 引擎修复桌面直接吃。本轮没有平行实现一套 agent。

推送前硬门槛（本机还没做手动 GUI）：

1. 第二笔提交里的 `Cargo.lock` 必须一起在（含 Tauri，且 `find-msvc-tools` 为 0.1.12）
2. `cargo check -p grok-session -p vesprism-desktop`（本机 `--jobs 1`）
3. `cd crates/vesprism-desktop && node scripts/verify.mjs`
4. 手动：冷启动 / 发消息 / 权限 / 问卷 / 子 Agent / 多 Tab
5. 这一批另看：用户消息不双份、后台任务条、切模型后的上下文窗口、项目技能（folder trust）、同文件并行编辑

**不要**为 TUI 的 `/context-window` 画面改桌面取消键。**不要**改 registry 里的 `cc` 源码来躲 `find-msvc-tools` 0.1.13。

不必做：Dashboard / pager chrome、Seatbelt、`grok worktree create`。
