## 3. 冲突怎么解

| 文件 | 倾向 | 处理 |
|------|------|------|
| `Cargo.lock` | 以编译为准 | 先取官方，再 `cargo check` 重生 |
| `model_switch.rs` | 两边都留 | 官方 `effort_override` 形参；保留本地 `systemPromptLabel` |
| `acp_session_impl/spawn.rs` | 两边都留 | 官方 title refresh + 本地 `resolved_mounted_flows` |
| `tool_taxonomy.rs` | 官方 | 收下 `WRITING_TOOL_WIRE_NAMES` / `writing_tool_kind` |
| `xai-tty-utils/src/lib.rs` | 官方 | 收下 `null_stdio`（`/dev/null` 被删后仍能 spawn） |

桌面专属路径无冲突。

### 3.1 胶水层适配

官方 1.0.4 起会话搜索不再用隐式全局索引，入口都要带 `SearchIndexManager` / `IndexDecision`：

- `delete_session_history(..., search_index)`：桌面传 `None`（与 `grok sessions delete` 一致；内部仍 `evict_session`）。
- `notify_session_updated(index, id, cwd)`：桌面 rename 传 `None`，下次 `search_sessions` 回填。
- `execute_search(decision, root, req)`：桌面 `search_sessions` 按 CLI 走 `start_if_enabled` + `IndexDecision::settled`。
