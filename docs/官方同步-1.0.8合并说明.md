## 3. 冲突怎么解

| 文件 | 倾向 | 处理 |
|------|------|------|
| `Cargo.lock` | 以编译为准 | 先取官方，再 `cargo check` 重生 |
| `xai-grok-shell/Cargo.toml` | 两边都留 | 官方 `config-docs` + 本地 `playground-tools` |
| `run_loop.rs` | 两边都留 | 官方 `is_family_switch` + 本地 `system_prompt_label` |
| `auth_error_no_retry_tests.rs` | 两边都留 | 调用补 `is_family_switch` 与 `system_prompt_label: None` |
| `sampler_turn.rs` | 官方结构 + 本地语义 | 测试迁到官方 `sampler_turn_tests.rs`；保留 `ToolOverrides.disabled` 继承 |
| `workflow/registry.rs` | 两边都留 | 官方 builtin `path` / bundled `compiled_in` + 本地 sidecar `contract` |

桌面专属路径无冲突。`vesprism-desktop` 仅修了一处既有 tsc 未使用 import，使 `verify.mjs` 通过。

### 3.1 胶水层适配

- `LaunchSpec` 新增 `effort`：本地 `flow_mount.rs` 挂载流程时补 `effort: None`。
- `handle_set_session_model` 新增 `is_family_switch`：`run_loop` / 测试 / 压缩回归补齐形参；**保留**桌面 `system_prompt_label`。
- `SessionUpdate` 新变体（elicitation 等）走 `grok-session` 的 `other` 分支，不会编译失败；桌面无专用 UI。
