## 5. 架构要点（读码入口）

```text
App.tsx
  └─ useDesktopApp()          # 会话/模型/工作区/设置/快捷键/toast
       ├─ sessionShellReducer # phase + engineStatus
       └─ useChatMessages()
            ├─ streamTypewriter  # append/push/flush/discard/seal/commitSealed
            └─ pendingPrompts

主区 MessageList（虚拟列表 + 测高缓存 + 贴底）
右侧 SidePanel（多标签：diff | tool-output | artifact）
权限 PermissionModal（kind 优先）
```

**会话 phase：**

`idle → booting → ready ⇄ restarting | loading → ready | failed`

**UI 派生：**

| 字段 | 含义 |
|------|------|
| `sessionPhase` | 壳层阶段 |
| `engineStatus` | 后端 ACP（含 generating） |
| `shellReady` | phase === ready |
| `loadingHistory` | phase === loading |
| `engineGenerating` | engineStatus === generating |
| `canMutateShell` | 非 busy，可 start/load/restart |
