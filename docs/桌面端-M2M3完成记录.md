## 四、如何验证

| 场景 | 期望 |
|------|------|
| 长对话上滑后流式 | 跳底角标不随打字狂涨，只在真正新气泡时 +1 |
| 切模型 | 顶部 toast，对话里无「已切换」系统气泡 |
| 设置温度清空 | 保存后 TOML 去掉 temperature；填 0 可写入 0.0 |
| 权限弹窗 | 拒绝类仍聚焦/Esc；kind 字段存在 |
| Ctrl+N / Ctrl+K | 新建会话 / 打开设置 |
| 侧栏会话很多 | 最多约 80 条摘要（limit） |
