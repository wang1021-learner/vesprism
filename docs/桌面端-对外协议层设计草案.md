# Vesprism 对外协议层设计草案（vsprism-protocol）

> 参照：OpenAI Codex `app-server` 协议（codex-rs/app-server-protocol v2）
> 目标：把 grok-session 能力暴露为独立 JSON-RPC 协议，供 VS Code 插件 / 第三方界面 / SDK 接入
> 状态：草案 v0.1

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| JSON-RPC 2.0 | 与 Codex app-server / MCP 同族 |
| 传输双通道 | stdio（本地进程）+ UDS（Windows 命名管道），后续可加 TCP |
| ndjson 分帧 | 每行一个 JSON 消息（与 ACP / dsh 一致） |
| 双向消息 | 请求（客户端→服务端）+ 通知（服务端→客户端，事件流） |
| 域划分 | session / turn / stream / approval / workbench / mcp / subagent / fs |
| 类型导出 | `generate-ts` 命令导出 TS 类型（照抄 Codex 做法） |

### 2.4 approval 域

| 方法 | 方向 | 参数 | 对应 |
|------|------|------|------|
| `approval/request` 通知 | S→C | `requestId`, `tool`, `description`, `options[]`, `autoGranted?` | `PermissionRequest` |
| `approval/respond` | C→S | `requestId`, `optionId` | respond_permission |

要点：
- 权限记忆自动放行 → 通知带 `autoGranted: true`，客户端可直接跳过 UI
- 选项语义对齐 dsh ACP：`allow_once` / `reject_once`，桌面端 UI 再映射"总是允许/本次会话"

## 3. 消息格式示例

```jsonc
// C→S 请求
{"jsonrpc":"2.0","id":1,"method":"session/start","params":{"cwd":"D:\\proj","flows":[]}}

// S→C 响应
{"jsonrpc":"2.0","id":1,"result":{"sessionId":"abc-123"}}

// S→C 事件（通知，无 id）
{"jsonrpc":"2.0","method":"stream/userTextChunk","params":{"sessionId":"abc-123","text":"hello"}}

// S→C 审批请求
{"jsonrpc":"2.0","method":"approval/request","params":{"requestId":5,"tool":"Execute","description":"类型：运行终端命令...","options":[{"id":"allow","name":"允许"},{"id":"deny","name":"拒绝"}]}}

// C→S 审批响应
{"jsonrpc":"2.0","id":2,"method":"approval/respond","params":{"requestId":5,"optionId":"allow"}}
```

## 4. 事件流生命周期

```
session/start → session/started
  ├─ turn/start（prompt 提交）
  │   ├─ stream/userTextChunk*（流式）
  │   ├─ tool/start → tool/update* → tool/end（走 approval 时插入 approval/request）
  │   └─ turn/end（stopReason: end_turn | max_tokens | cancelled）
  └─ subagent/spawned → subagent/progress* → subagent/finished
```

## 5. 实施步骤

| 阶段 | 内容 | 产出 |
|------|------|------|
| P1 | 新建 `vsprism-protocol` crate：类型定义 + 域枚举 | 协议类型 |
| P2 | 新建 `vsprism-app-server`：stdio/UDS 传输 + 路由到 grok-session | 本地服务可跑 |
| P3 | 事件桥：GrokSession 事件流 → 协议通知（复用 session_update_to_event） | 流式协议通 |
| P4 | approval 桥 + workbench 域 | 审批/agent 资产可用 |
| P5 | `generate-ts` 导出 + TS SDK（@vesprism/sdk） | 对外 SDK |

## 6. 风险与取舍

- **stdin 冲突**：服务端 stdin 是协议线，日志必须走 stderr（照抄 dsh-acp-demo）
- **会话所有权**：一个连接可持多 session（照抄 dsh bridge 的 SessionRecord map）
- **断连清理**：连接断开 → 取消所有持有 session 的回合（照抄 dsh quiesce）
- **权限记忆**：自动放行事件带 `autoGranted` 标记，避免客户端误弹 UI
- **版本**：`initialize` 返回 protocolVersion + capabilities（照抄 ACP）
