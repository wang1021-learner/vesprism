# 桌面端模型字段 vs 官方 `ModelEntryConfig` 对照

> 日期：2026-07-26（GUI 对齐后修订）  
> 官方结构：`crates/codegen/xai-grok-shell/src/agent/config.rs` → `ModelEntryConfig` / `ConfigModelOverride`  
> 桌面 DTO：`crates/jike-grok-desktop/src-tauri/src/commands.rs` → `ModelEntryDto`  
> 桌面 UI：`SettingsModal` + `types.ModelEntry`  
> 官方用户文档：`xai-grok-pager/docs/user-guide/11-custom-models.md`  
> 当日改动详述：`../Grok build 桌面化改造 笔记 第八天.md` §6–§7

---

## 1. 结论摘要

| | 说明 |
|--|------|
| 官方 per-model 可配置项 | **30+** |
| 桌面 GUI 已暴露 | **连接 + 推理开关 + 密钥 + 高级折叠**（见 §2） |
| 多厂商 | ✅ `api_backend` 三选一 + `extra_headers` 多行编辑 |
| 推理 | ✅ 设置勾选能力；会话 Composer **滑条**热切 `meta.reasoningEffort` |
| 仍不做 | 全局 `[models]` 采样默认 UI；`api_key` 写 toml；`name` 与 model 分离；`system_prompt_label` 自由编辑 |

**引擎早已支持多家 + 自定义；今日补齐桌面读写与交互。**  
未暴露字段仍可手写 `$GROK_HOME/config.toml`；`upsert_model_entry` **按键覆盖、不 clear 整表**，未知键一般保留。

## 2. 命名与 id 约定

| 概念 | 字段 | UI |
|------|------|-----|
| 配置段主键 | `[model.<id>]` / `id` | 自动 `m-…`，**永不展示** |
| API 模型 id | `model` | **「模型名称」**（唯一名称框） |
| 展示名 | `name` | 无独立框；保存强制 `name = model` |
| 密钥 | `env_key` + `.env` | 自动 env 名；Key 区只处理明文写入/已配置状态 |
| 系统人设标签 | `system_prompt_label` | 无 UI；保存自动生成 |

列表、Composer 下拉主文案：`model || id`（正常情况只看到 API 名）。

## 3. 桌面已暴露字段

### 3.1 连接（常显）

| 字段 | 桌面 UI | 读写 | 说明 |
|------|---------|------|------|
| `id` | 无 | ✅ | 自动生成 |
| `model` | ✅ 模型名称 | ✅ | 即 API id |
| `name` | 无独立框 | ✅ = model | |
| `base_url` | ✅ | ✅ | 必填 |
| `api_backend` | ✅ 三选一卡片 | ✅ | `chat_completions` / `responses` / `messages` |
| `context_window` | ✅ 上下文 (K) | ✅ | UI 用 K，存盘 token = K×1000；必填 |
| `description` | ✅ | ✅ 可选 | |
| `env_key` | 隐式 | ✅ | 密钥走 `.env` |

### 3.2 推理（常显开关 + 会话滑条）

| 字段 | 设置页 | Composer | 读写 |
|------|--------|----------|------|
| `supports_reasoning_effort` | ✅ 勾选 | 控制滑条是否出现 | ✅ |
| `reasoning_effort` | 勾选时默认写 `medium` | 滑条改**会话**档（ACP meta） | ✅ 配置默认 |
| `reasoning_efforts` | 无 UI | — | ✅ 勾选时写满六档数组 |

会话热切：`set_current_model(modelId, reasoningEffort?)` → `GrokSession::set_model` → meta `reasoningEffort`。

### 3.3 密钥

| 项 | 说明 |
|----|------|
| `api_key`（toml） | ❌ 桌面不写 |
| `.env` + `env_key` | ✅ `save_env_key` / `get_env_status`（仅 is_set） |

### 3.4 高级折叠

| 字段 | UI 标签要点 | 写盘约定 |
|------|-------------|----------|
| `temperature` / `top_p` | 温度 / 核采样 | `>0` 写，否则 remove |
| `max_completion_tokens` | 最大生成长度 | 同上 |
| `api_base_url` | API 专用地址 | 空 = 与 base_url 同，remove |
| `max_retries` | 最大重试 | `>0` 写 |
| `inference_idle_timeout_secs` | 流式空闲超时 | `>0` 写 |
| `stream_tool_calls` | 默认/开/关 三态 | `null` 不写 |
| `auto_compact_threshold_percent` | 自动压缩阈值 % | `1–100` 写，`0` remove |
| `agent_type` | 智能体类型 | 默认 `grok-build` |
| `use_concise` | 简洁模式 | 仅 true 写 |
| `extra_headers` | 多行 `Header: value` | 空表 remove |
| `hidden` | 隐藏模型 | 仅 true 写 |
| `supported_in_api` | API Key 用户可见 | 默认 true 省略；false 才写 |
| `laziness_detector.enabled` | 懒惰检测启用 | 子表 |
| `laziness_detector.max_nudges_per_session` | 每会话最大提醒 | 子表，`>0` |
| `compactions_remaining` | 剩余压缩次数 | `""`/`dynamic`/`off`/数字 |
| `compaction_at_tokens` | 压缩触发 Token | 同上 + 自定义数字 |
| `system_prompt_label` | 无 UI | 保存自动写 |

### 3.5 会话与 catalog

| 能力 | 状态 |
|------|------|
| `[models].default` | ✅ 设置页当前选中 id |
| `reload_models` | ✅ 保存后热重载 catalog |
| `set_current_model` / 热切换 | ✅ 含可选 reasoning |
| 全局 `[models]` 默认采样/头 | ❌ 本期不做 UI |

## 4. 仍未 GUI 暴露（可手写 toml，upsert 一般保留）

| 字段 | 说明 |
|------|------|
| `api_key` | 官方支持 toml 明文；桌面坚持 env |
| `auth_scheme` | 鉴权方案 |
| `supports_backend_search` | 后端搜索 |
| `show_model_fingerprint` | 调试 |
| `reasoning_efforts` 自定义子集 | 桌面固定写标准六档 |
| 全局 `[models].temperature` 等 | 非 per-model |

## 6. 示例（GUI 可完整产生，无需手补协议）

```toml
[models]
default = "m-a1b2c3d4e5f6"

[model.m-a1b2c3d4e5f6]
model = "claude-sonnet-4-6"
name = "claude-sonnet-4-6"
base_url = "https://api.anthropic.com"
env_key = "JIKE_KEY_EXAMPLE"
context_window = 200000
api_backend = "messages"
supports_reasoning_effort = true
reasoning_effort = "medium"
reasoning_efforts = ["none", "minimal", "low", "medium", "high", "xhigh"]
agent_type = "grok-build"
extra_headers = { anthropic-version = "2023-06-01" }
```

DeepSeek / OpenAI 兼容：

```toml
[model.m-deepseek]
model = "deepseek-chat"
name = "deepseek-chat"
base_url = "https://api.deepseek.com/v1"
api_backend = "chat_completions"
context_window = 128000
env_key = "DEEPSEEK_API_KEY"
```

保存设置后会 `reload_models`；手改磁盘需再保存设置或重启 App。
