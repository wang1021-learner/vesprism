# 桌面端 · 会话级组装层（半插件化）设计

> 状态：设计稿 v0.4（对照审查锁定：诚实面板 / 回放 / 别名 / deny 顺序 / 官方补原语）
> 原则：**官方补原语、桌面做预设**——官方已有能力一律复用；缺口按 P3 门槛下沉会话原语，不在 GUI 假装生效。
> 对照：`docs/Vesprism-全功能与实现手册.md`、官方同步说明。

## 1. 目标

给每个会话（Tab）一份「组装单」，决定该会话的：人设、模型、工具集（开关+参数）、技能范围、权限策略、工作流、MCP 服务器。官方引擎行为不变，组装层只做「配置 → 官方机制」的翻译与编排。

## 2. 组装单格式（YAML，三级继承叠加）

```yaml
# ~/.vesprism/compositions/coding.yml —— 用户级
id: coding
extends: default            # 内置 default → 用户级 → 工作区 .grok/agent.yml → 会话覆盖
persona:
  label: senior-engineer    # 官方 system_prompt_label（apply 经 set_model _meta.systemPromptLabel）
model:
  name: deepseek-chat
  reasoning_effort: medium
tools:
  disable: [bash, web_search]   # 别名 bash→run_terminal_command；未知名加载失败
permissions:
  mode: ask                    # ask | yolo | auto → 官方 x.ai/yolo_mode_changed
  rules:
    - match: "bash:*"
      policy: ask
    - match: "edit:**/.env"
      policy: deny
```

P0 面板只编辑上述已接线字段。`persona.sections` / skills / mcp / plugins / `workflows.auto_run` **已从产品面拿掉**（schema 若再写 `workflows` 会因 deny_unknown_fields 拒收）。

合并规则：后层覆盖前层；列表默认**替换**（extends 语义与 cordis patch 一致：只写差异）。

## 4. 会话区 UI：目标 / 任务 / 提问（官方事件 → 桌面落点）

### 4.1 目标（Goal）——官方是完整多智能体编排，桌面只差薄壳

官方引擎（已核实）：`update_goal` 工具；`goal_tracker.rs` 维护 `GoalStatus` 8 态（active / user_paused / back_off_paused / no_progress_paused / infra_paused / blocked / budget_limited / complete）、`GoalPhase` 3 态（idle/planning/executing）；规划者→工作者→验证者(skeptics)→策略家角色编排、token 预算、自动暂停退避、`/goal` 斜杠命令、goal 角色模型配置与 kill-switch。

## 9. P1 功能落地记录
