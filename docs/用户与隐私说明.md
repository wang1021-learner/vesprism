# Grok 桌面客户端 · 用户与隐私说明（草案）

> 面向发布前的能力与数据处理说明。M1（密钥链等）未完成前，对外宜标「预览版」。

## 本应用会做什么

- 在您选择的**工作区目录**内读写文件、执行 Agent 允许的工具（读、改、终端等，受权限弹窗约束）。
- 将会话摘要与配置保存在本机独立目录（默认与官方 CLI 隔离的 `GROK_HOME`，如 `~/.jike-grok-desktop`）。
- 使用您配置的 **API 地址与密钥** 调用大模型服务（请求发往您填写的厂商端点）。

## 本应用不会默认做的事

- 不会将对话内容上传到 xAI / 极客之外的第三方分析服务（模型请求除外，那是您配置的 API）。
- 不会在未授权时扫描全盘；工作区路径由您选择。
- 当前预览版密钥可能仍落在本机配置目录的 `.env`（**M1 计划迁系统密钥链**）。

## 权限

- 危险操作会弹出**权限确认**；Esc 优先触发拒绝类选项（若存在）。
- 请勿在不受信任的仓库上启用「始终允许」类选项。

## 快捷键（当前）

| 快捷键 | 作用 |
|--------|------|
| Ctrl/Cmd + N | 新建对话 |
| Ctrl/Cmd + K 或 , | 打开设置 |
| Esc | 权限弹窗拒绝（若有拒绝项）；侧栏关闭等 |

## 反馈

问题与崩溃请附本机日志（Tauri 本地 log）与复现步骤。
